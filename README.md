# clljj 图间 · 算法练习本

纯静态的个人算法练习本，支持手机和电脑浏览器。包含 25 道练习、6 道带来源链接的平台原题、思路和代码笔记、自填判题报告、学习足迹与 Markdown 导出。

## 手机使用

GitHub Pages 发布后，通过网站地址打开，可使用浏览器菜单“添加到主屏幕”。不需要安装依赖或运行后端；本版不提供离线缓存。

首次在手机使用：在电脑版导出完整 JSON 备份，再到手机版页面底部点“导入备份”。数据保存在各自浏览器，不会自动同步；导入会替换目标设备当前记录。

## 发布

仓库 Settings → Pages → Source 选择 Deploy from a branch；Branch 选择 main，Folder 选择 /docs，保存。页面文件位于 docs/index.html。

## 数据与判题

本项目没有服务器数据收集和账号系统。公开文件只含网页、题目内容与图标，不含使用者在浏览器中的代码、笔记或报告。运行时无分析统计或第三方脚本。

点击原题按钮，自行登录对应平台提交；判题报告由使用者手填，平台结果与代码会在保存报告时一起留存。GPT 无需联网查询成绩。

## 题目来源

前 19 道为本练习本整理的本地练习，不能视为任何平台同名原题。第 20～25 道附公开来源链接、中文概述与首个基本样例：

- AtCoder Educational DP Contest：Frog 1、Frog 2、Vacation、Knapsack 1。
- CSES：Minimizing Coins、Movie Festival。

提交要求以原平台为准。题目相关权利归原权利人，不代表获得原平台的官方授权或合作。网页保留来源和核对日期。

## 本地使用与开发

直接打开 docs/index.html 即可。无需构建。不要将导出的个人 JSON 备份、提交批改文件、密钥或日志提交到仓库。
