这一版优化了什么

默认半分辨率采集，识别线程直接提交点击，减少悬浮界面刷新。加入“连续10次”测试，显示中位数、P95 和分段耗时。

升级后这样测
  1. 开启无障碍、授权整个屏幕采集。
  2. 先用默认“50%采集＋直达＋1帧”，进入测试页，移开悬浮条后点“连续10次”。
  3. 再切换“100%采集＋关闭直达”作对照。更改分辨率后要保存设置并重新授权采集。

目标是降低延迟；实际提速需要手机实测，未承诺低于 50 ms。测试总时间仍从提交变色开始，包含渲染等待。

画面只在本机内存处理，不保存、不上传。进入实际目标页面后，请重新选择监测点和点击位置。
