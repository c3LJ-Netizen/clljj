红绿快点

屏幕从红色变成绿色，自动点击指定位置。

Android 8.0 及以上 · 版本 1.0 · APK 33 KB

下载安卓安装包 APK 下载 ZIP 备用包 APK 下载失败时可以尝试 ZIP。下载 ZIP 后，先在手机文件管理器中解压，再打开里面的 APK 安装。

下载与使用

  1. 请用手机自带浏览器或 Chrome 打开本页，再点下载。
  2. 安装后，在应用中开启无障碍点击，并同意屏幕采集。
  3. 选择监测点和点击位置，再按开始。先看到红色，之后变绿才触发。

默认第一帧变绿即请求点击，无额外等待。实际速度取决于手机；可用应用里的测试页查看。

屏幕颜色只在本机处理，不保存、不上传。此为个人签名安装包，仅支持安卓。
